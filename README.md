Dalam pembangunan antaramuka web, HTML dan CSS berfungsi secara bersepadu untuk membina dan memformatkan halaman. Berikut adalah ringkasannya:

Struktur Asas (HTML): HTML bertindak untuk membina kerangka kandungan menggunakan tag khusus, seperti <nav> untuk menu navigasi dan <div> untuk ruang kandungan utama. Tanpa fail gaya, pelayar (browser) hanya akan memaparkan struktur ini sebagai teks biasa yang tidak tersusun.

Pemformatan Visual (CSS): CSS digunakan untuk menetapkan reka bentuk visual seperti warna, saiz, dan susun atur. Melalui kaedah Internal CSS, kod gaya diletakkan di dalam tag <style>. CSS menggunakan tiga jenis pemilih (selector) utama untuk menyasarkan elemen:

Pemilih Tag: Menyasarkan elemen secara langsung melalui nama tag (cth: nav).

Pemilih ID: Menggunakan simbol # untuk elemen beridentiti unik (cth: #intro).

Pemilih Kelas (Class): Menggunakan simbol . untuk penetapan gaya yang boleh dikongsi oleh pelbagai elemen (cth: .btn-primary).
